# Student Management System – Admin Backend

## Project Overview
This folder contains the Admin Backend module of the Student Management System.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js
- Multer

## Admin Features
1. Admin Profile Management
2. Update Admin Profile
3. Change Admin Password
4. Upload Admin Profile Image
5. JWT-based Admin Authentication

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/admin/profile | Get Admin Profile |
| PUT | /api/admin/profile | Update Admin Profile |
| PUT | /api/admin/change-password | Change Password |
| POST | /api/admin/upload-image | Upload Profile Image |

## API Documentation
See `docs/ADMIN_API.md` for detailed API information.

## Testing
All four Admin APIs have been tested successfully using Postman.
